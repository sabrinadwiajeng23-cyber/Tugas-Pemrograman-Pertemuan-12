Struktur Data

Program akan menggunakan Class DaftarNilai untuk enkapsulasi logika pengelolaan data.
Data mahasiswa (Nama dan Nilai) akan disimpan dalam atribut data_mahasiswa, yang merupakan list/dictionary.

Fungsi Metode
tambah(nama, nilai):
Fungsi: Menambahkan data mahasiswa baru (Nama dan Nilai) ke dalam data_mahasiswa.
Logika: Membuat entri baru dan menambahkannya ke koleksi.
tampilkan():
Fungsi: Menampilkan semua data mahasiswa yang tersimpan (Nama dan Nilai) secara terstruktur.
Logika: Iterasi melalui data_mahasiswa dan mencetak setiap entri.
hapus(nama):
Fungsi: Mencari dan menghapus data mahasiswa berdasarkan nama yang dimasukkan.
Logika: Mencari nama dalam koleksi. Jika ditemukan, entri tersebut dihapus. Jika tidak, tampilkan pesan error.
ubah(nama, nilai_baru):
Fungsi: Mencari mahasiswa berdasarkan nama dan memperbarui nilai mereka dengan nilai_baru.
Logika: Mencari nama dalam koleksi. Jika ditemukan, nilai yang terkait diperbarui. Jika tidak, tampilkan pesan error.
